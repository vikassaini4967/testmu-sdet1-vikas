## What broke
The app’s layout does not constrain width for small viewports, causing the document’s scrollWidth to exceed clientWidth by ~90 px. No test or selector issue; the failure is deterministic and reproducible. This horizontal overflow is a user‑visible defect on mobile screens.

## Suggested fix
In the main stylesheet (e.g., `styles.css`), add a rule to prevent horizontal overflow for small screens:

```css
/* Prevent horizontal scrolling on mobile */
@media (max-width: 420px) {
  html, body {
    overflow-x: hidden;
  }
}
```

Or adjust the container widths/flex settings so elements never exceed the viewport width.
